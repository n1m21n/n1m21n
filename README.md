### 🌌 What I'm Building: **[Infinite](https://github.com/n1m21n/Infinite)**

> **A unified node-based audiovisual modular workstation for macOS & Windows.**  
> Real-time GPU video shaders, procedural 3D geometry & simulations, and a full modular synthesizer rack with AU/VST3 plugin hosting — interconnected through a universal modulation graph.

<details open>
<summary><b>✨ Key Capabilities & Systems in Infinite</b></summary>

<br/>

| Domain | Highlights & Superpowers |
| :--- | :--- |
| **🎨 Real-Time GPU Shaders** | **160+ nodes**, live GLSL fragment editor, SDF primitives, feedback loops, Gray-Scott reaction-diffusion, 31 blend modes, Oklab color grading, and on-device ML background segmentation. |
| **🪐 Procedural 3D & Physics** | PBD Cloth & soft-body simulation, fixed-timestep particle systems, point scattering, single-draw-call GPU instancing (`glDrawElementsInstanced`), Cook-Torrance GGX PBR, and 32-bit HDRI lighting. |
| **🎛️ Modular Synthesizers** | Wavetable synthesis (12 tables, 8 morphable frames), modal physical modeling (Metallic resonators), real-time granular synthesis, spectral PaulStretch, multi-sample player, and 8-track drum machine. |
| **🔌 Universal Cross-Modulation** | Modulate **any slider from anything**: extract FFT frequency bands from live audio to deform 3D meshes, or turn live video motion vectors into synthesizer control voltages (CV). |
| **🎹 Audio Unit & VST3 Hosting** | Host third-party plugins with native floating GUI windows. Touch any plugin parameter to expose modulatable pins directly on the patch canvas. |

</details>
